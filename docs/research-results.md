# v0.5 무안내 직접 탐색과 안내 배정 비교

2026-10-30 수행. 기존 Nearest는 전체 빈자리 위치를 알고 진입 시 예약하는 안내 전략이었다. 일반 운전자의 자리 탐색을 구현하지 않았으므로 무안내 주차 대비 효과를 평가할 수 없었다. 이번 버전은 직접 탐색을 공통 교통 엔진에 추가하고 기본 비교를 수정했다. 최종보고서 본문과 구별되는 재현 자료다.

## 비교 설계

1. **무안내 search**: 입장한 차량이 도달한 자리만 확인한다. 점유 중이면 통과하고, 한 통로를 확인한 뒤 외곽 순환로를 거쳐 다음 통로로 이동한다. 전역 빈자리·출차 예측·미래 수요를 사용하지 않는다. 첫 자리가 비어 있으면 임의의 추가 지연 없이 주차한다.
2. **Nearest 안내**: 전체 가용 자리를 알고 가까운 면을 진입 시 예약한다. search→Nearest는 위치 안내·예약의 효과다.
3. **RL 안내**: 학습한 정책으로 가용 자리를 선택·예약한다. Nearest→RL은 안내 전략 사이의 추가 효과다. 안내 효과를 RL 고유 효과로 주장하지 않는다.

전략마다 동일한 차량 수요·배경 주차·실제 출차 요청·도로망을 사용한다. 면수에 대한 공통 입장 제한은 주차 중·주차 목적 진입 중·탐색 중 차량 수의 합에 적용한다. 무안내 운전자에게 빈자리 위치를 알려주는 규칙이 아니다. 안내는 진입 시, 무안내는 현장 발견 시 공간을 차지한다. 무안내는 네 통로 전체를 확인하고 입구로 돌아왔는데도 주차하지 못했으면 포기하며, 이후 출구 이동도 비용에 포함한다. 단순한 진입 즉시 만차 거절·검색 성공·검색 실패를 구분한다.

반환 도로는 같은 도로망에 추가한 합성 순환로다. 기존 안내 경로보다 짧은 경로를 만들지 않아 기존 안내 관찰·전이를 유지한다. 원래 학습한18개 정책을 유지하고 다시 평가했으며 새로 재학습했다고 표현하지 않는다. 추가 모델 요소가 안내의 상태·지표를 바꾸지 않는 회귀 테스트를 포함한다.

## 지표·통계

주차시간은 입장→주차 완료다. 탐색 시간은 실제 입장한 무안내 차량의 입장→발견/포기까지 이동·대기를 포함한다. 우회거리는 최종 주차 면까지 최단 입차 경로를 초과한 실제 주행거리이며 성공 차량 기준이다. 포기·입장 거절은 별도 지표로 보존하고 실패 탐색의 이동 비용도 누락하지 않는다.

안내와 무안내에서 모두 주차한 같은 차량ID에 대해 주차시간·총 이동거리 차이를 계산한다. 이 공통 성공 집합에도 선택 편향이 남으므로 미배정률과 함께 보고한다. 전체 성공 차량 평균끼리만 빼서 동일 차량 효과라고 해석하지 않는다.

조건별 평균과 교통seed 편차·학습seed 편차를 분리한다. 대응 차이는 같은 입력의 같은 교통seed를 사용한다. 학습×공유 교통seed crossed bootstrap2,000회(seed42)의 탐색적95% 구간이다. 기준 전략끼리는 교통seed만 재표집한다. 아래 표는 환경별 고정된27조건을 동일 가중치로 평균한 뒤 재표집하며, 조건을 독립 시설 표본으로 세지 않는다. 다중 비교 보정은 하지 않았다.

## 운전자 탐색 가정에 대한 민감도

아래는 중간 규모·오차6의3유형/층 평균이며, 일반 안내 − 무안내의 공통 성공 차량 주차시간 차이다. 조건별 구간·원자료는 search-sensitivity.json에 있다. 첫 통로에 모두 몰리는 큰 개선 수치만 골라 기본 결과로 제시하지 않았다.

| 환경       | 분산 시작 | 첫 통로부터 시작 |
| ---------- | --------: | ---------------: |
| 기본20면   |    -3.137 |          -28.896 |
| 공항80면   |    -3.059 |          -53.877 |
| 비대칭20면 |    -3.135 |          -28.843 |

첫 통로 시작에서는 여러 운전자가 같은 통로를 확인하고 돌아 나와야 해 차이가 커진다. 이 민감도는 운전자 행동 가정의 영향이 크다는 증거다. 실제 탐색 시간 감소량을 주장하려면 차량 궤적·시야·통로 선택·인내시간을 실측으로 보정해야 한다.

## 한계

직접 탐색 모델은 실제 운전자 궤적으로 보정되지 않았다. 도달한 자리만 보는 시야, 정해진 통로 순서, 한 번의 전체 통로 탐색, 공통 입장 제한, 안내 준수·예약의 정확성은 통제 가정이다. 혼합 안내율·오작동·자유 진입·장외 대기·보행시간·교차로 충돌은 포함하지 않는다. 공항의 점유율은 관측값이지만 개별 차량 수요·도로·반환 순환로는 합성이다.

이 결과는 해당 합성 모델에서의 안내 효과이며 실제 공항 운영 효율이나 현실 예측력을 검증한 결과가 아니다. RL의 추가 효과는 별도로 판단해야 한다.
