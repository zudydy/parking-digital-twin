# v0.4 실험 프로토콜과 결과

2026-10-30 수행. 최종보고서 본문이 아니라 재현 설정·결과 해석·그림 위치를 정리한 구현 자료다.

## 고정된 실험 설계

- 환경: 기본20면, 공항80면, 비대칭20면. 환경별 수요 유형 또는 층 3종.
- 규모: 기본/비대칭35·70·110대, 공항100·180·260대. 예측 오차 ±0·6·20 tick.
- 정책: Nearest, Random, Rule, RL full, RL no-departure, 학습 전 초기 정책. 마지막 세 정책은 학습 seed11·23·47 각각 평가.
- 학습: 18정책 × 200 episode. 동일 curriculum에서 학습 traffic seed1000~1199. 검증 traffic seed50001~50003. 검증은 유형/층×규모×오차27조건이며 각 규모·오차 조합에 seed[(규모index+오차index)%3]를 사용한다. 50 episode마다 검증하며 미배정률→운영비용/입력 차량 순으로 checkpoint를 선택한다.
- 평가: traffic seed90001~90030. 3환경×3유형/층×3규모×3오차=81조건, 각30개 동일 입력에서12실행(기준 전략3 + 학습3 + 제외3 + 초기3). 총29,160회. 조건별6전략 요약486개다.
- 공항 초기화 스냅샷은2026-10-30 20:27:23 KST 고정. 실제8개 관측 시계열은 별도이며 학습/시험 선택에 사용하지 않았다.

정책은 테스트 결과로 선택하지 않는다. 모든 학습 seed를 평가하고, 시연용 대표 정책만 검증 결과로 선택한다. 출차정보 제외 조건은 관련 입력을 제거한 상태에서 별도 학습했다. 학습 전 초기 정책은 동일 seed의 초기 신경망에 가용 행동 마스킹만 적용한다. 모든 전략은 같은 조건·traffic seed의 완전히 같은 시나리오 SHA-256을 가진다.

## 통계의 의미

조건별 막대는 학습·교통 seed 전체 평균이다. trafficStd는 각 교통 seed에서 학습 seed를 평균한30개 값의 표본 표준편차, learningStd는 각 학습 seed에서 교통 seed를 평균한3개 값의 표본 표준편차다. 두 편차를 동일하게 해석하지 않는다.

대응 차이는 같은 traffic seed와 같은 조건에서 계산한다. 학습3개와 교통30개 축을 각각 복원 추출하고, 교통 인덱스는 학습 seed 사이에 공유하는 crossed bootstrap 2,000회(seed42)의 percentile95% 구간을 사용한다. 출차정보 사용/제외는 같은 학습 seed·traffic seed끼리 대응한다. 기준 전략은 학습 축이 없다.

아래 전체 요약은 **환경별 고정된27조건을 동일 가중치로 평균**한 후 학습×교통 축을 bootstrap한다. 조건을 독립 표본으로 세지 않고 시설·수요 종류 모집단으로 추론하지 않는다. 여러 조건을 탐색하며 다중 비교 보정은 하지 않았다. 학습3개만으로 넓은 알고리즘 우수성·일반적인 통계적 유의성을 주장하지 않는다. bootstrap구간이0을 제외하더라도 해당 설계와 표본의 탐색적 결과로 제한한다.

## 실제 결과

표의 값은 RL full − Nearest 평균 차이 [탐색적95% 구간]이다. 음수는 RL의 해당 지표 감소다. 미배정률(%p)을 먼저 확인해야 하며 미배정률 차이가 불확실한 상태에서 운영비용만으로 종합 우수성을 주장하지 않는다.

| 환경        |          미배정률 차이(%p) | 운영비용/입력 차량 차이(tick) |
| ----------- | -------------------------: | ----------------------------: |
| 기본 20면   | +0.0000 [-0.0082, +0.0079] |    -0.1318 [-0.1786, -0.0862] |
| 공항 80면   | -0.0117 [-0.0512, +0.0267] |    +0.0148 [-0.0389, +0.0687] |
| 비대칭 20면 | -0.0019 [-0.0101, +0.0045] |    -0.0009 [-0.0436, +0.0385] |

기본 환경에서는 평균 미배정률 차이가 사실상0이며 운영비용/입력 차량이 약0.132 tick 감소했다. 공항은 두 지표의 구간이 모두0을 포함한다. 비대칭 환경도 Nearest 대비 비용·처리율의 분명한 개선은 확인되지 않았다. 거리 차이가 있는 환경을 만들었다는 사실과 RL의 성능 향상은 별개다.

비대칭 설계의 운영비용에서는 출차정보 사용의 감소가 관찰되지만 다른 환경에서 일관된 정보 효과는 확인되지 않았다. 처리율 차이도 불확실하다. 학습 예산200 episode·소형 네트워크·압축 관찰의 한계가 있으며, 이 실험이 정보의 무효성이나 DQN의 최적성을 증명하지 않는다. 학습 전 정책도 전체 원자료와 화면의6전략 비교에 포함되어 있다.

## 재현·파일·그림

```bash
pnpm research:train 200
pnpm research:publish
pnpm research:evaluate
pnpm research:verify
pnpm figures
pnpm research:provenance
```

- manifest: 학습/검증/시험 분리,18정책 해시, 초기화 관측값. published.json은 검증 선택 기록.
- runs.csv.gz: 실행별 모든 지표·학습/교통seed·정책 ID·입력 해시.
- analysis.json:81조건×6전략의 평균·두 종류 편차·대응 차이·조건별30교통 점.
- overall.json: 위27조건 평균 표의 원본. provenance.json: 소스·설정·결과 SHA-256.
- training/*.json:200 episode의 손실·수요·보상점수·검증 곡선. 손실이 낮아지는 것과 정책 효용이 개선되는 것은 다르다.
- figures/{standard,airport,asymmetric}-{summary,learning,sensitivity}.{png,svg}:300dpi PNG·벡터SVG. matplotlib으로 재생성한다. 기본/비대칭은공연장70대, 공항은지상180대가 대표 성능 비교 그림이며 제목에 조건을 명시한다. 민감도는같은수요유형/층의3×3조건이다. 학습 그림은6개seed/입력조건을 모두 표시한다.

324개 대표 실행을 독립 재실행하여 전체 지표(오차1e-8이하)와 입력 해시가 저장값과 일치했다. 전체29,160행의2,430개 동일 입력 그룹과18정책 해시도 검사했다.

## 보고서에서 가능한 주장과 남은 한계

공통 엔진·실제 공개 집계값 초기화·학습 정책·반복 비교·제거 실험·대체 레이아웃·관측 수집 및 오차 확인 흐름을 구현하고 재현 자료를 보존했다는 주장은 가능하다. **실제 인천공항 운영 효율 향상, 현실 예측력, RL의 일반적 우수성은 검증되지 않았다.**

공항 모델의80면 축소·합성 수요, 추상tick, 짧은 관측 구간,3학습seed, 제한된학습 예산, 모델 및 목적함수 선택의 영향은 한계다. 실제 개별차량 기록·도면·장기 관측과 시간 보정, 추가 학습 예산·다른 알고리즘·시설 검증은 후속 연구로 구분한다. 기존v0.3의 비용은 목적함수가 달라 직접 비교하지 않으며 archive로 보존한다.
