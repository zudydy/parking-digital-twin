> v0.3 인천공항 80면, 초기 주차 차량, 긴 간선의 진입 간격과 2.5D 규약은 [공항 모델 문서](incheon-data.md)를 우선 적용한다. 아래 기본 20면 실험의 규칙과 별개로 구분한다.

# 모델·학습·평가 규약

## 교통 모델

- 기본 20면, 4개 구역, 입구 1개·출구 1개의 단순화한 단방향 도로 그래프다. 실제 시설을 측정한 레이아웃이 아니다.
- 시간 1 tick은 추상 단위이며 실제 초·분으로 환산하지 않는다. 통로 간선은 기본 1 tick, 동시 차량 용량 1이다. 모델의 거리는 간선 이동 tick의 합으로 정의한다.
- 노드의 수용량은 무제한이다. 교차로 충돌·차량 길이·차간거리·회전·보행자·통로 역류는 모델링하지 않는다. 대기는 노드에서 다음 간선을 기다리는 FIFO 대기다.
- 같은 시각에는 이동 완료 → 주차 완료·출차 요청 → 이동 시작과 공간 해제 → 도착 차량 배정 순서로 처리한다. 같은 시각의 도착은 입력 순서를 유지한다. 간선 대기 우선순위는 요청 시각과 큐 진입 순번이다.
- 배정 순간부터 주차면을 예약한다. 출차를 요청해도 통로에 진입하지 못하면 주차면을 계속 점유한다. 첫 출차 간선에 진입하면 예약·점유를 해제한다.
- 주차면에 도착한 뒤 주차 조작에 1 tick을 사용한다. CSV `duration`은 주차 완료 이후 체류시간이다. 합성 시나리오는 절대 출차 요청 시각을 사용하되 주차 완료 후 최소 1 tick 체류한다.
- CSV의 예상 출차는 도착+체류+6 tick의 단순 추정값이다. 합성 시나리오의 실제 출차 요청과 정책이 보는 예상 출차는 별도다. 예상치에는 설정한 오차가 들어가며 정책은 실제 요청 시각이나 미래 차량 목록에 접근하지 못한다.
- 만차 차량은 입구에서 미배정 처리하며 재시도하지 않는다. 통로 대기와 미배정은 다른 개념이다.

기본 단방향 직사각형에서는 어느 주차면을 사용해도 입구부터 출구까지 총 경로 길이가 11이다. 따라서 총 이동거리 차이가 아니라 입차/출차 시간의 배분, 통로 지연, 미배정 차이를 관찰하는 모델이다. 정책별로 거리 차이가 나타난다고 해석하지 않는다.

## 지표

- 주차 소요시간: 도착 → 주차 완료. 주차 조작 1 tick과 통로 대기를 포함한다.
- 출차 소요시간: 실제 출차 요청 → 출구 도달. 출차 대기를 포함한다.
- 이동거리: 입차와 출차 경로의 이동 tick 합. 대기는 제외한다.
- 누적 지연: 모든 차량의 통로 대기 tick 합. 주차 조작·체류시간은 제외한다.
- 평균 점유율: 고정 관측 구간 `[0, observationEnd)`의 주차 완료 차량 수를 적분하여 면수×관측시간으로 나눈다. 예약 후 이동 중인 차량은 제외하고, 출차 요청 후 자리에서 대기하는 차량은 포함한다.
- 처리율·미배정률: 전체 입력 차량을 분모로 한다. 시간·거리 평균은 배정 차량을 분모로 하므로 반드시 미배정률과 함께 비교한다.
- 누적 비용: 모든 차량의 이동 tick + 주차 조작 tick + 통로 대기 tick + 미배정 대수×30. 체류 자체는 비용이 아니다. 각 tick 비용과 미배정 페널티의 가중치는 1, 30이다.
- 관측 구간 후에도 남은 차량이 모두 출구에 도달할 때까지 계산하여 출차 지연과 비용이 잘리지 않게 한다. 점유율만 고정 관측 구간을 사용한다.

## 강화학습

외부 ML 런타임 없이 TypeScript에서 103→32(tanh)→20 선형 출력의 Q 신경망을 구현했다. 이는 픽셀 입력의 원 논문 아키텍처를 복제한 것이 아니라, 주차 상태 벡터를 위한 소형 DQN이다. 경험 재생과 별도 target network는 [Mnih et al., 2015](https://doi.org/10.1038/nature14236)의 DQN 구조를 따른다.

- 상태: 현재 시각·예상 잔여 체류·전체 예약률 3개와 각 주차면의 가용 여부·입차거리·출차거리·관련 통로 대기·근접 예상 출차 집중도 5개씩, 총 103개.
- 행동: 현재 빈 주차면 20개 중 하나. 학습 시 탐험·최댓값 추론과 bootstrap target 모두 가용 행동만 사용한다.
- 만차 입차는 정책 행동 없이 미배정 처리되며 이후 다음 의사결정까지 발생한 비용에 포함된다.
- 전이: 배정 1회에서 다음 배정 가능 차량 도착까지. 마지막 배정 뒤에는 모든 차량의 출차까지 진행한다.
- 보상: 전이 중 증가한 누적 비용의 음수 / 20. 출차 지연의 비용도 포함한다.
- 할인율: 의사결정마다 0.98. 물리적 tick마다 할인하는 semi-MDP는 아니다. 실제 관찰은 압축 상태이므로 완전한 Markov 상태를 보장하지 않는다.
- Huber loss, RMSProp, 학습률 0.0003, replay 10,000개, batch 16, 4결정마다 업데이트, 100업데이트마다 target 복사.
- epsilon 1→0.08, 학습 seed와 검증 seed·최종 평가 seed는 분리한다.
- 여러 시나리오를 순환하며 학습하고 25 episode마다 3시나리오×3검증 seed 평균 비용으로 checkpoint를 선택한다. 최종 평가 데이터로 checkpoint를 선택하지 않는다.
- `public/policy.json`은 실제 학습한 가중치와 학습 설정이다. 웹은 저장된 정책을 읽어 추론하며 학습하지 않는다.
- `experiments/training.json`에 학습 비용·손실·검증 비용을 기록한다. 학습 episode마다 수요가 달라지므로 개별 비용의 감소만으로 학습 성공을 판단하지 않는다.

## 실험과 재현

`pnpm train 450 20261027`로 정책을 생성하고 `pnpm evaluate 30`으로 독립 평가한다. 결과는 `experiments/`에 저장된다. 동일 엔진·동일 차량 입력·동일 관측 구간을 각 전략에 사용하고, 결과에는 입력과 정책의 SHA-256을 기록한다. 평균과 표본 표준편차를 함께 보고한다. 비교는 이 합성 모델 안에서의 결과이며 실제 시설 효과나 통계적 유의성을 주장하지 않는다.
