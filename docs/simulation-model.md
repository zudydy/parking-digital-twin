# 모델·학습·평가 규약 · v0.5

## 교통 모델

단방향 그래프의 간선 이동, 유한 통로 용량, FIFO 노드 대기, 이동 중 주차면 예약을 계산한다. 같은 tick은 이동 완료 → 주차 완료·출차 준비 → 이동 시작·공간 해제 → 도착 배정 순서다. 만차는 재시도 없이 미배정한다. 주차 조작은 1 tick이다. 통로의 `headway`는 진입 간격이며 용량과 별개다. 노드는 무제한 대기 공간으로, 충돌·차간거리·보행자·교차로 우선권은 모델링하지 않는다.

- 기본 20면: 사무실·공연장·쇼핑몰, 모든 주차면의 입차+출차 경로는 11이다.
- 공항 80면: 공식 점유율로 초기화한 합성 배경 차량, 세 층, 총 경로 38. [공항 데이터 규약](incheon-data.md) 참조.
- 비대칭 20면: 기본 그래프에 출구 B와 진입 간격 3 tick의 독립 간선을 추가한다. 첫 행 총 경로는 8, 나머지는 11이다. 모든 면에서 도달 가능한 출구 중 정적 최단 경로를 선택한다. 실측 도면이나 동적 경로 최적화가 아니다. RL 유리함을 가정하지 않는 통제 환경이다.

## 무안내 탐색 · local-systematic-v1

`search`는 전역 후보 목록으로 주차면을 고르는 전략 함수를 호출하지 않는다. 같은 교통 엔진에서 입장하고, 차량이 실제 도달한 노드의 주차면 하나만 확인한다. 비어 있으면 즉시 공간을 차지하고 공통1 tick 주차 조작을 시작한다. 점유 중이면 전진한다. 원격 빈자리·다른 차량의 출차 예측·미래 수요를 이용하지 않는다.

기본은 차량ID·시나리오seed로 첫 통로를 분산하고 이후 통로를 순서대로 한 바퀴씩 확인한다. 대안은 모두 첫 통로부터 시작한다. 각 통로를 끝까지 확인하면 동쪽 연결로·외곽 순환로를 거쳐 입구에서 다음 통로로 진입한다. 네 통로를 모두 확인하고 입구로 돌아왔는데도 주차하지 못했으면 탐색 포기를 기록하고 출구로 이동한다. 포기 후 퇴장 이동도 운영비용에 포함한다. 재시도에 가상 대기시간을 추가하지 않는다.

순환로는 모든 전략에 공통으로 추가한 양의 비용 경로이며 기존 출구 전에 분기한다. 안내 경로가 순환로를 사용할 이점은 없고 기존 안내 최단 경로·관찰이 유지됨을 검사한다. 실측 시설의 진입·반환 도로가 아니다. 시각화는 동일한 간선 궤적을 재생한다.

입장 제한은 주차 중·진입 중·직접 탐색 중 차량의 합이 면수에 도달하면 새 차량을 거절하는 공통 규칙이다. 출차 차량은 기존 규칙대로 주차면을 떠나는 첫 간선 진입 시 공간을 해제한다. 무안내 운전자가 전체 빈자리 위치를 아는 것은 아니며 총 주차 수요를 제한하는 동일 입장 조건이다. 자유 진입·장외 대기·재진입 모델까지 구현한 것은 아니다.

`spotFoundAt`은 안내에서는 진입 배정 시각, 직접 탐색에서는 실제 현장 발견 시각이다. 탐색 중 차량의 최종 주차면을 과거 화면에 미리 표시하지 않는다. 자리별 현장 확인 시각·점유 여부를 `searchChecks`에 보존한다. 탐색 중인 차를 미배정으로 세지 않고, 입장 거절과 탐색 후 포기를 구별한다.

- 평균 탐색 시간: 실제 입장한 무안내 차량의 입장→발견/포기 시간. 이동·대기를 포함하고 안내는0이다. 안내 차량의 이동시간까지0이라는 뜻이 아니다.
- 탐색 주행거리: 탐색 중 이동한 간선 시간 합. 실패한 탐색도 포함한다.
- 평균 우회거리: 주차 성공 차량의 실제 탐색 경로에서 최종 면까지 최단 입차 경로를 뺀 값. 실패 차량은 제외한다.
- 공통 성공 차량의 주차시간·거리 차이: 두 방식에서 모두 주차한 동일ID만 대응한다. 성공 집합 선택 편향이 남으므로 미배정률·포기 수를 함께 보고한다.

## 출차 시각과 지표

합성 수요의 원래 절대 출차 요청은 `departureRequestedAt`에 보존한다. 주차 완료가 늦어지면 물리적 준비 시각 `departureReadyAt = max(parkedAt+1, 원래 요청)`으로 계산하고 그 차이를 별도로 기록한다. CSV의 `duration`은 주차 완료 이후 체류시간이므로 원래 요청은 `parkedAt+duration`이며 준비 지연이 없다. 미배정 차량의 준비 시각은 null이다.

| 지표                | 정의                                                  |
| ------------------- | ----------------------------------------------------- |
| 주차 소요           | 주차 완료 − 도착                                      |
| 출차 준비 후 소요   | 출구 도달 − 물리적 준비                               |
| 원래 요청 대비 출차 | 출구 도달 − 원래 요청                                 |
| 출차 준비 지연      | 물리적 준비 − 원래 요청                               |
| 이동거리            | 입차+출차 간선 이동 tick 합; 대기 제외                |
| 통로 지연           | 간선 진입을 기다린 tick 합                            |
| 운영비용 C          | 이동 + 주차 조작 + 통로 대기 + 출차 준비 지연         |
| 처리율·미배정률     | 입력 차량 수 기준                                     |
| 평균 점유율         | 고정 관측 구간의 주차 완료 차량 수 적분 / (면수×시간) |

시간·거리 평균은 배정된 신규 차량만 포함한다. 전체 운영비용·통로 지연·점유율은 초기 배경 차량도 포함한다. 따라서 공항의 `operatingCost / inputVehicleCount`는 배경 차량 비용까지 신규 입력 수로 나눈 시스템 지표이며 배정 차량 한 대의 평균 비용과 다르다. 모든 차량이 출구에 도달할 때까지 계산하고 점유율만 고정 관측 구간으로 제한한다. 체류 자체는 비용이 아니다. 시간은 실측 초·분으로 보정되지 않은 tick이다.

## 서비스 우선 목적함수

v0.3의 미배정 페널티 30은 공항의 정상 이동·주차 39보다 작았다. v0.4에서는 단일 실행의 점수를 `J = R + C/(S+C)`로 정의한다. R은 미배정 대수, C는 비음수 운영비용, S는 양의 고정 규모 상수다. `S=max(1, (신규+배경 차량 수) × (최대 입차+출차 경로+1))`이며 동일 입력의 전략에는 같다.

운영 항은 항상 [0,1) 안에 있으므로 미배정 한 대의 차이가 어떤 유한 운영비용 차이보다 우선한다. 동률에서는 운영비용이 작은 전략을 선호한다. 단일 실행의 성질이며 여러 실행의 J 평균에 사전식 순서를 주장하지 않는다. 여러 조건의 검증·정책 선택에서는 **평균 미배정률을 먼저**, 동률(수치 오차 1e-10 이내)이면 **평균 운영비용/입력 차량**을 비교한다. 서로 처리율이 다른 전략의 운영비용만으로 우열을 정하지 않는다.

전이 보상은 `−100 × ΔJ`, 첫 결정 전 발생한 비용부터 마지막 출차까지 보존한다. 할인율 γ=1로 전체 보상 합이 −100J와 일치한다. 보상 스케일 100은 학습 수치의 크기만 바꾼다. 다만 운영비용 항이 압축되고 거부가 드문 구간은 신호가 작아 학습이 어렵다. 이 목적함수로 RL이 최적 정책을 학습했다고 보장하지 않는다.

## DQN

TypeScript 소형 Q 신경망, 20면은 103→32(tanh)→20, 80면은 403→48(tanh)→80이다. 경험 재생과 target network는 [Mnih et al., 2015](https://doi.org/10.1038/nature14236)의 구조를 참고한다. 원 논문의 픽셀 아키텍처를 복제한 것은 아니다.

- 관찰: 시각·예상 잔여 체류·예약률, 각 면의 가용 여부·입차거리·출차거리·통로 대기·예상 출차 집중도.
- 출차정보 제외 정책: 예상 잔여 체류와 면별 출차 집중도를 0으로 마스킹하고 처음부터 별도 학습한다. 추론 때만 정보를 지운 정책이 아니다.
- 실제 출차 요청·미래 차량 목록은 정책에 제공하지 않는다. 배정 가능한 도착이 의사결정이며 만차는 자동 처리한다.
- 탐험·탐욕 선택·bootstrap target 모두 가용 행동만 사용한다.
- Huber loss, RMSProp, 학습률 0.0003, replay 12,000, batch 16, 4결정마다 업데이트, 100업데이트마다 target 복사, epsilon 1→0.06.
- 상태는 압축 관찰이며 완전한 Markov 상태를 보장하지 않는다. γ=1의 유한 episode 실험이다.
- 정책 파일은 schema 2, 목적함수·환경·입력 조건을 명시한다. v0.3 파일은 현재 추론에서 거부하며 archive로 보존한다.

배정 검사기는 배정 직전 관찰, 가용 후보와 Q값을 보존한다. Q값은 누적 보상 추정이며 인과 설명이나 확률이 아니다. 화면의 경로·차량 애니메이션은 엔진 결과를 보간한다.
