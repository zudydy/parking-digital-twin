# 주차장 디지털 트윈 최소 프로토타입

중간보고서에서 Nearest 주차 배정 방식과 기본 지표 계산을 보여주기 위한
TypeScript CLI 시뮬레이션입니다. 외부 서버나 데이터베이스 없이 로컬에서
동일한 입력을 반복 실행할 수 있습니다.

## 실행 방법

Node.js 20 이상과 npm이 필요합니다.

```bash
npm install
npm start
```

다른 CSV 파일을 사용하려면 경로를 추가합니다.

```bash
npm start -- path/to/vehicles.csv
```

테스트와 타입 검사는 다음 명령으로 실행합니다.

```bash
npm test
npm run typecheck
```

## 입력 형식

CSV 헤더는 아래와 같이 고정되어 있습니다.

```csv
vehicleId,arrivalTime,duration
CAR-001,0,6
CAR-002,1,5
```

- `vehicleId`: 중복되지 않는 차량 ID
- `arrivalTime`: 0 이상의 정수 도착 시각
- `duration`: 1 이상의 정수 주차 시간
- 시간은 분이나 초로 한정하지 않은 추상 단위입니다.

## 시뮬레이션 규칙

- 주차장은 4행 5열, 총 20면입니다.
- 입구는 `(0, 0)`이고 주차면은 `(1, 1)`부터 행 우선으로 배치됩니다.
- 입구와 주차면 사이의 맨해튼 거리가 가장 짧은 빈 주차면을 선택합니다.
- 거리가 같으면 주차면 번호가 작은 곳을 먼저 선택합니다.
- 같은 시각에는 출차를 먼저 처리하며, 같은 시각에 도착한 차량은 CSV 순서를 따릅니다.
- 만차 시 차량은 대기하지 않고 `미배정`으로 기록됩니다.

평균 이동거리는 배정된 차량의 편도 거리 평균입니다. 평균 점유율은 첫 차량의
도착부터 마지막 도착 또는 출차까지의 구간에서 점유된 면적을 시간가중 방식으로
계산합니다.

```text
평균 점유율 = 모든 배정 차량의 주차 시간 합 / (20 × 전체 시뮬레이션 시간) × 100
```

## 출력 예시

```text
=== 주차장 시뮬레이션 결과 ===
총 차량 수: 8대
평균 이동거리: 2.75
평균 점유율: 13.21%

차량별 배정 주차면
- CAR-001: 도착 0, 출차 6, 1번 주차면
...
```

## 현재 구현 범위

- CSV 기반 차량 입·출차 이벤트
- 20개 주차면과 Nearest 배정 알고리즘
- 만차 차량 미배정 처리
- 총 차량 수, 평균 이동거리, 시간가중 평균 점유율, 차량별 배정 결과 출력
- 입력 검증 및 핵심 로직 자동 테스트

강화학습, 웹 UI, 데이터베이스, 서버 및 배포 기능은 현재 범위에 포함하지 않습니다.
